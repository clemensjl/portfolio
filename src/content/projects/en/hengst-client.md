Hengst Client is a launcher for Minecraft: Java Edition. It aims to start any game version at the highest possible FPS and pull in mods and modpacks straight from Modrinth and CurseForge, without the ads and detours many launchers come with.

The core is written in Rust and can already download and prepare any vanilla version from the command line. Next up are Microsoft account sign-in, the desktop app and mod support.

Status: pre-alpha, licensed under GPL-3.0. Not an official Minecraft product.
