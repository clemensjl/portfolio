Hengst Client is a launcher for Minecraft: Java Edition. The goal is to start any game version at the highest possible FPS and to pull in mods and modpacks straight from Modrinth and CurseForge, without the ads and detours that come with many launchers.

The core is written in Rust. From the command line, it can already download any vanilla version and get it ready to play. Next up are signing in with a Microsoft account, the desktop app and mod support.

Status: pre-alpha, licensed under GPL-3.0. Not an official Minecraft product.
