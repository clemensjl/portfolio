A collection of Agent Skills in the Agent Skills format, usable in Claude Code, Cursor and Codex. Each skill is a Markdown file with instructions that the agent loads as soon as the task calls for it.

The focus is Austrian law — legal-at covers imprint requirements, GDPR, the FAGG (distance selling act), cookies and accessibility. That is exactly where generic English-language templates are not just imprecise but plainly wrong: they know neither the ECG and UGB nor the Austrian deadlines and mandatory disclosures.

Install via `npx skills@latest add clemensjl/claude-skills`.
