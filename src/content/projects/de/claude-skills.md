Eine Sammlung von Agent Skills im Agent-Skills-Format, nutzbar in Claude Code, Cursor und Codex. Jeder Skill ist eine Markdown-Datei mit Anweisungen, die der Agent lädt, sobald die Aufgabe dazu passt.

Der Schwerpunkt liegt auf österreichischem Recht — legal-at deckt Impressum, DSGVO, FAGG, Cookies und Barrierefreiheit ab. Genau dort sind generische englischsprachige Vorlagen nicht nur ungenau, sondern schlicht falsch: Sie kennen weder ECG und UGB noch die österreichischen Fristen und Pflichtangaben.

Installation über `npx skills@latest add clemensjl/claude-skills`.
